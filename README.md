# 미래기술 Power User 학습앱 (FutureTech Power User Learning App)

Android 네이티브 기반 **"미래 기술 Power User 훈련 앱"** 입니다.
취업·자격증용 암기 앱이 아닌, 디지털/AI 기술의 구조를 이해하고 판단·검증할 수 있는 능력을 키우는 앱입니다.

## 핵심 기능
1. **초급 (8개 유닛) + 중급 (10개 유닛) 커리큘럼**:
   - 쉬운 설명 → 결과 예상 → 구조/코드 읽기 → 수정 → 실행 → 빈칸 채우기 → 디버깅 → 힌트 → AI 검증 → 설명하기 → 간격 반복
2. **안전한 코드 실행 샌드박스 (Sandboxed Engine)**:
   - Python, SQL, TypeScript, HTML/CSS/JS 지원
   - 타임아웃(3초) 및 무한루프 방지
   - 앱 DB/KeyStore/민감 파일 접근 및 외부 네트워크 차단 보안 격리 (Escape Test 통과)
3. **간격 반복 (Spaced Repetition) & 개인 오류 노트**:
   - 1일, 3일, 7일, 14일 복습 주기 자동 관리
   - 자주 틀린 오답 및 실습 에러 자동 수집
4. **실전 제작 모드 & 2대 프로젝트**:
   - 초급 프로젝트: 주식 점수 분류 미니앱
   - 중급 프로젝트: 개인 주식 연구 미니앱 (종목 검색 → API → DB → Python → AI)
   - 사용자 자연어 아이디어 분해 및 맞춤형 5단계 프로젝트 생성
