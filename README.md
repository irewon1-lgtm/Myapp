# 미래기술 Power User 학습앱

Android 네이티브 기반 **미래 기술 Power User 훈련 앱**입니다.
취업·자격증·코딩테스트용 암기 앱이 아니라, AI가 만든 코드와 디지털 시스템을 **읽고, 판단하고, 직접 수정하고, 실행하고, 검증할 수 있는 사용자**를 만드는 것이 목적입니다.

## 현재 커리큘럼
- 초급: 8개 모듈 × Level 1~5 = **40개 마이크로 레슨**
- 중급: 10개 모듈 × Level 1~5 = **50개 마이크로 레슨**
- 전체: **90개 레슨**
- 설계 학습량: 약 40시간 이상 + 1/3/7/14일 간격 반복 복습
- 이전 레슨을 완료해야 다음 레슨이 열리는 순차 해금 구조

## 한 레슨의 10단계 능동 학습
1. 쉬운 개념 설명
2. 실행 전 결과 예상
3. 코드/구조 읽기 문제
4. 한 부분 직접 수정하고 실행
5. 핵심 개념 빈칸 문제
6. 보지 않고 짧은 코드 다시 작성
7. 고장난 코드 디버깅
8. AI의 그럴듯한 오답 판별
9. 원본을 바꿔 새 상황에 적용하는 작은 응용 미션
10. 본인 말 설명 + 핵심 개념 포함률 기반 숙련 확인

문제를 풀지 않고 단순히 `다음`만 눌러 끝낼 수 없도록 주요 단계에 통과 조건이 있습니다. 실패한 빈칸·직접 작성·실행·디버깅·AI 판별·응용 미션은 개인 오류 노트에 누적됩니다.

## 초급 모듈
1. 컴퓨터·스마트폰·인터넷 구조
2. AI 기본 원리
3. AI 제대로 사용하기
4. 정보 검색과 검증
5. 프로그램의 사고방식
6. Python 기초
7. 데이터 기본
8. 보안 기초

## 중급 모듈
1. HTML/CSS/JavaScript 구조
2. TypeScript 읽기와 수정
3. API와 HTTP
4. SQL/Database
5. Python 자동화
6. Git/GitHub 버전관리
7. 오류 찾기와 테스트
8. 자연어 코딩과 AI 협업
9. AI 앱 기본
10. 자동화 기본

## 학습 원칙
사람이 반드시 익힐 것:
- 구조
- 판단
- 검증
- 문제 분해
- 데이터 흐름
- 보안 감각
- 오류 범위 좁히기
- AI 지시 능력

AI에게 적극 맡겨도 되는 것:
- 긴 코드 초안
- 반복 코드
- 보일러플레이트
- 반복 데이터 변환
- 복잡한 명령 초안
- 테스트 코드 초안

핵심은 문법을 전부 외우는 것이 아니라 **AI가 만든 결과가 맞는지 읽고 검증하고 고칠 수 있는 능력**입니다.

## 현재 구현 구조
- Kotlin + Jetpack Compose Android 네이티브
- Room DB: 진도, 개인 오류 노트, 간격 반복
- 학습용 코드 실행 샌드박스
- HTML/JS 안전 미리보기
- SQL 별도 연습 DB
- 초급/중급 프로젝트 화면

## 검증
`fix/problem-engine-v2` 브랜치 기준 GitHub Actions에서 다음을 실행합니다.

```bash
./gradlew testDebugUnitTest --stacktrace
./gradlew assembleDebug --stacktrace
```

90개 레슨 구조, 5단계 모듈 진행, 문제 데이터 완전성, 빈칸 채점, 디버깅 채점, 자기 설명 핵심개념 평가를 Unit Test로 검사합니다.
