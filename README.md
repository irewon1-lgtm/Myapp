## 소스-배포 추적

- 챗북의 정본은 이 브랜치 `chatbook-app-20260923`입니다.
- 소스 변경은 `Chatbook source verification` 워크플로에서 자동으로 테스트·빌드됩니다.
- 모든 배포 빌드는 `/version.json`에 앱 버전, Git branch, 정확한 source SHA, build 시각을 기록합니다.
- 앱의 ‘챗북에 대하여’ 화면에도 배포된 source SHA 앞 7자리를 표시합니다.
- 빠른 배포는 배포 후 운영 주소의 `/version.json`이 트리거한 Git SHA와 일치하지 않으면 실패 처리합니다.
- 기존 `/api/sync`는 구버전 앱 호환용으로 유지하고, 새 앱은 pull/push/reset 전용 엔드포인트를 사용합니다.

## 정확한 범위

- APK가 아니라 웹앱입니다.
- 이미지형 PDF는 한글 모양을 보존하지만 텍스트 검색/선택이 안 됩니다. 브라우저 인쇄가 텍스트 기반 대안이며 PPTX 텍스트는 편집됩니다.
- 닫힌 앱에 정해진 시각으로 보내는 서버 예약 푸시는 미구현입니다. 앱 내 알림 및 앱 실행 중 허용된 기기 알림만 제공됩니다.
- 동기화는 연결 코드 방식이며 이메일/Google 로그인 방식이 아닙니다.
- 사용자가 가져온 책의 원문과 다운로드 파일 원본은 자동 동기화하지 않습니다. 책 원문은 백업/복원으로 옮깁니다.
- 브라우저 저장 데이터를 지우면 연결되지 않은 기록이 사라질 수 있습니다.
- 새 책 자동 받기는 실제 발행된 책 수신이며 ChatGPT/YouTube 자동 분석이 아닙니다.
- 목업의 고정 숫자·가짜 저자명은 사용하지 않았고 실제 화면 폭에 따라 줄바꿈과 페이지 수가 달라집니다.

## 배포 보안

CI는 한 실행에 한 번만 사용하는 공개 키를 발행하고, 암호화된 배포 입력을 받아 실행합니다. 배포 토큰/연결 코드/사용자 기록을 저장소·로그·ZIP에 쓰지 마세요. .deployment의 암호문은 만료된 실행 기록이지 재사용 가능한 배포 설정이 아닙니다.

책 표지·장식은 사용자 제공 이미지에서 추출했습니다. 글꼴 파일은 포함하지 않습니다. PptxGenJS 라이선스는 public/vendor에 있습니다.
