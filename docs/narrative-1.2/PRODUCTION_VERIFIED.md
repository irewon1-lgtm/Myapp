## 교재 변경

`파이썬 1시간 완전 초보 교재`를 `원문 보존·연결형 초보자 해설판`으로 교체했다. 14장, 기존 블록 ID 191개, 기존 개념도 10개, 퀴즈 36개를 유지했다. 본문과 코드의 문자 수는 15,066에서 28,698로 늘었고 블록은 191에서 325개가 됐다. 길이 목표로 채운 것이 아니라 연결 설명과 실행 가능한 예시를 보강한 결과다. 다른 12권과 저장된 영어 전사 원본의 해시는 유지됐다.

원문/한국어 기준본/추가 설명의 출처는 내부에 구분하고 읽는 본문은 자연스럽게 연결했다. 획일적인 뜻-이유-실수 카드와 강제 페이지 목표는 두지 않았다. 분석 구간과 읽는 장을 분리하고 연결 문맥은 한정했다. 기존 비용 예약, 제한된 재시도, 중간 저장, 원문 대조 규칙은 유지했다. 자동 외부 모델 호출은 OFF이며 이번 작업에서 외부 AI API를 호출하지 않았다.

## 한계와 재현

물리 Galaxy 기기를 시험하지 않았다. 저장된 영어 전사와 기존 원고를 기반으로 편집했으며, 원 강의의 음성·화면 전체를 새로 검증한 결과는 아니다. 실제 2~3시간 새 영상의 모델 생성 성공률, 과금, 처리시간은 측정하지 않았다. 기존 개념도는 유지했고 YouTube 영상 프레임 차단 문제는 이번 작업 범위에서 해결하지 않았다. 코드/구조 검사는 원문의 의미를 100% 보존했다거나 사람이 모두 이해한다는 보증이 아니다.

초기 소스 전달 실행 35856011036은 109개 검사와 39개 코드 검사 및 빌드까지 통과했으나, 자동 생성된 public/sw.js의 미스테이징으로 rebase가 중단됐다. 생성 파일만 복원한 실행 35856411231에서 동일 패치의 소스 저장을 완료했고, 위 운영 배포를 수행했다. 책 전체를 다시 생성하지 않았다.
