현재 교재 제작 기준

엔진 1.2.0 · 기준 8f188430ce8f

영상의 실제 내용을 충실한 한국어로 보존하고, 코딩 0일차가 질문했을 때 설명해 주는 깊이로 풀어 쓴 연결형 교재. 요약 목록이나 강의 카드 모음으로 만들지 않는다.

다른 방에서는 이 현재본을 읽고 아래 규칙과 예시를 함께 적용합니다. 이력·옛 예시는 여기에 누적하지 않습니다.

집필 기준

  1. 확보한 원문·코드·실행 결과를 기준으로 설명, 예제, 비유, 조건, 예외, 전환을 보존한다. 영상 제목이나 모델 기억으로 원문을 대신하지 않는다. 미확인 음성·화면·구간은 미확인으로 남긴다.
  2. 영어 원문을 먼저 짧게 요약하지 않는다. 의미와 부정·조건·숫자·단위를 보존해 한국어 기준 내용을 만든다. 새 용어는 한국어와 영어를 연결하고 코드 원형과 학습용 수정 예제를 구분한다.
  3. 분석은 개념 경계에서 입력 한도에 맞춰 작게 나누고 저장한다. 집필은 장·절 단위로 연결한다. 현재 구간의 원문, 필요한 앞뒤 문맥, 이미 설명한 용어만 전달하며 전체 영상·이전 본문을 매번 재투입하지 않는다.
  4. 처음 나오는 용어·기호·생략된 과정과 독자가 왜 그런지 물을 부분을 본문 안에서 충분히 설명한다. 설명에 필요한 선행 개념도 풀되, 이미 배운 내용을 매번 처음부터 반복하지 않는다.
  5. 앞 문단에서 생긴 의문을 다음 문단이 해결하도록 쓴다. 뜻·이유·주의사항·퀴즈 같은 고정 항목을 모든 개념에 강제하지 않는다. 책처럼 쓰되 필요한 코드·표·그림·실행 결과는 본문에 배치한다.
  6. 원문에서 배운 내용과 챗북이 덧붙인 해설·예시는 출처를 구분한다. 원문 오류는 몰래 고치지 않고 밝힌다. 새 사실은 확인하고 근거를 남긴다. 영상 프레임을 못 얻었으면 개념도를 실제 화면이라고 표시하지 않는다.
  7. 각 장에 필요한 용어 설명과 예시·사용법을 제공하고, 확인 문제에는 정답 이유를 쓴다. 코드의 새롭거나 어려운 부분은 값과 실행 순서를 풀어준다. 실행하지 않은 코드는 검증했다고 쓰지 않는다.
  8. 페이지·문단 수를 강제하지 않는다. 중복으로 분량을 늘리거나 완성된 책을 다시 요약하지 않는다. 시간표뿐 아니라 실제 개념·코드·예제·조건의 누락과 오역을 대조하고 문장 연결을 읽어 확인한다.
  9. 수정은 문제 있는 절에 한정하고 정상 본문·원문·식별자를 보존한다. 미확인 내용은 보류하되 초안을 삭제하지 않는다. 부족한 설명은 편집하며 전체 재작성·무한 재시도·추가 AI 심사 단계를 자동으로 붙이지 않는다.

대표 본문 예시 — 입력한 값을 계산에 사용하기

「파이썬 1시간 완전 초보 교재」 v3, User Input 절의 선택 발췌. 저장된 전사 기반 본문과 챗북 보충 해설의 문체 예시이며 영상 원문 인용이나 모든 절의 고정 틀이 아닙니다.

키보드로 숫자를 쳤다는 사실만으로 값의 자료형이 정해지지는 않습니다. input()의 반환값, 즉 input이 일을 마친 뒤 돌려주는 값은 문자열입니다. 그래서 사용자가 25를 입력하면 정수 25가 아니라 문자열 "25"를 받습니다. 설명에서 붙인 따옴표는 자료형을 보여 주는 표기이고, 입력할 때 따옴표까지 치라는 뜻은 아닙니다.

이 상태에서 1을 더하려고 하면 String과 Integer를 섞는 Type Error가 발생하는 예시를 보여 줍니다.

나이처럼 정수 계산이 필요하면 `int()`로 변환해야 합니다. 영상은 입력받은 age를 Integer로 바꾼 뒤 1을 더하는 과정을 보여 줍니다.

int(input(...))에서 바깥 int가 숫자로 바꾸려면 먼저 바꿀 대상이 필요합니다. 따라서 안쪽 input을 실행해 답을 받고, 그 문자열을 int에 전달하고, 변환 결과를 age에 대입합니다. 괄호가 두 쌍인 이유는 두 함수 각각의 시작과 끝이 있기 때문입니다. 왼쪽부터 단어 순서대로 실행한다기보다, 바깥 기능에 필요한 안쪽 결과를 먼저 준비한다고 이해하면 됩니다.

age = int(input("Age: "))
print(age + 1)

입력 예: 25. 아래 결과에서는 키보드 입력 자체의 화면 메아리는 생략했습니다.

Age: 26

입력받고, 필요하면 변환하고, 계산한 뒤 출력하는 흐름이 연결됐습니다. 하지만 모든 사용자에게 같은 문장을 보여 줄 필요는 없습니다. 이제 나이에 따라 서로 다른 결과를 고르는 조건문을 보겠습니다.

사용과 수정

작업 시작 시 이 현재본을 실제로 읽고 engineVersion·contentDigest·규격 사본을 작업 기록에 저장한다. 과거 규격을 합쳐 쓰지 않는다.

진행 중인 책은 저장한 규격 사본으로 이어간다. 공통 기준 변경은 다음 새 책부터 적용하고, 사용자가 요청할 때만 진행 중인 책을 변경한다.

이번 책만의 요청은 해당 책에만 적용한다. 공통 기준을 바꾸라는 요청이 있을 때만 원본 정책을 수정한다.

현재본을 읽지 못하면 최신 기준 확인 불가라고 알린다. 임의 규격을 최신판이라고 주장하지 않는다. 기존 책과 초안을 삭제하지 않는다.

public/engine/learning-policy.json의 authoring만 차이 편집한다. 폐기 규칙·옛 예시는 현재본에서 제거하고 Git 이력은 기본 제작 입력에 넣지 않는다. 문체 변경 시 예시도 함께 검토한다.

교재 작성과 앱 등록은 별개다. 등록할 때만 승인된 저장소에서 현재 데이터 계약을 확인하고 기존 책 ID·메모를 보존한다. 공개 규격은 수정·배포 권한을 주지 않는다.

확인 범위

구조 검사와 해시는 번역·문장 품질·영상 접근 성공이나 AI의 규격 준수를 보증하지 않는다.

영상 분석은 구간별로 처리하지만 최종 본문은 장·절 단위로 연결한다. 이 공개 문서는 영상 생성 API가 아니다.
