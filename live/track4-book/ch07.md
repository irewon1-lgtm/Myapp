# 7장. Python에서 JavaScript로 — 아는 개념을 새 문법에 연결하기

지금까지 만든 입력창은 값을 적을 자리를 제공하고, CSS는 그 자리를 읽고 누르기 좋게 배치했습니다. 그러나 ‘입력한 시간을 숫자로 바꾼다’, ‘빈 기록이면 추가하지 않는다’, ‘목록에 새 항목을 넣는다’ 같은 판단과 처리는 아직 없습니다. 이제 JavaScript를 사용해 이런 규칙을 작성합니다.

새 언어를 만났다고 앞에서 배운 내용을 버릴 필요는 없습니다. 변수에 값을 연결하고, 조건에 따라 실행하고, 목록에서 하나씩 꺼내고, 함수로 일을 묶는 개념은 다시 나타납니다. 달라지는 것은 표현하는 문법과 일부 동작 규칙입니다. 이 장은 문법을 빠르게 훑는 목록이 아니라, 짧은 코드를 실제 값으로 끝까지 따라가는 연결 과정입니다.

먼저 실행 환경을 구별하겠습니다. 이 장에서 `console.log`로 출력하는 예제는 JavaScript 콘솔에서 결과를 확인하는 코드입니다. HTML 문서의 본문에 글자가 자동으로 생기는 코드가 아닙니다. `print`를 쓰는 Python 실행창에 그대로 넣어서도 실행되지 않습니다. ‘어떤 언어를 어디에서 실행하는가’를 확인한 뒤 코드를 읽어야 합니다.

## 7.1 let과 const는 값을 사용하는 이름을 만든다

Python에서 `minutes = 20`이라고 적었다면 JavaScript에서는 다음과 같은 표현을 만나게 됩니다.

```javascript console
let minutes = 20;
minutes = minutes + 10;
console.log(minutes);
```

```text
30
```

첫 줄의 `let`은 이 이름을 선언한다는 표기입니다. `minutes`라는 이름에 숫자20을 연결합니다. 둘째 줄은 기존 minutes 값을 읽어10을 더한 뒤 그 결과를 minutes에 다시 넣습니다. 등호는 양쪽이 같은지 묻는 질문이 아니라 오른쪽 계산 결과를 왼쪽 이름에 대입하는 표기입니다. 이 점은 Python에서 배운 대입과 연결됩니다.

셋째 줄의 `console.log(minutes)`는 현재 minutes 값을 콘솔로 보냅니다. `console`이 제공하는 `log` 기능을 호출하는 모양입니다. 점은 그 대상의 기능이나 속성에 접근하는 표기로 사용됩니다. 괄호 안에는 넘길 값을 적습니다. 이 예제에서는30이 넘어가므로 콘솔에30이 보입니다.

`const`도 자주 사용합니다. 선언한 이름에 다른 값을 다시 대입하지 않을 때 사용합니다.

```javascript console
const topic = "HTML";
console.log(topic);
```

```text
HTML
```

문자열을 표현하는 따옴표 자체가 출력되는 것은 아닙니다. 따옴표는 코드에서 문자열의 경계를 표시합니다. `const`라고 선언한 뒤 `topic = "CSS"`처럼 같은 이름에 다른 값을 다시 대입하려 하면 오류가 납니다. 그러나 const가 이름에 연결된 객체의 내부 변경까지 모두 막는다는 뜻은 아닙니다. 배열과 객체를 배운 뒤 그 차이를 다시 확인하겠습니다.[1][2][3]

### 연습 7-1. 값의 변화를 차례로 따라가기

다음 코드의 출력은 무엇인가요? 마지막 줄만 보고 추측하지 말고 각 대입 뒤 minutes 값을 적어 보세요.

```javascript console
let minutes = 15;
minutes = minutes * 2;
minutes = minutes - 5;
console.log(minutes);
```

### 풀이 7-1

처음15, 두 번째 대입 뒤30, 세 번째 대입 뒤25이므로25가 출력됩니다. `minutes * 2`가 이전 값을 읽어 계산한다는 점이 핵심입니다. `minutes`라는 이름이 어떤 특별한 시간 계산 기능을 가진 것은 아닙니다. 같은 자리에 `a`라는 이름을 쓰더라도 모든 사용처를 맞추면 계산 규칙은 같습니다.

`let`은 처음 이름을 만들 때 사용했고, 이후의 대입에는 같은 선언을 반복하지 않았습니다. 코드의 역할을 변수 이름의 영어 뜻과 문법의 동작으로 나누어 읽어 보세요.

## 7.2 문자열 숫자와 실제 숫자를 구분하기

입력창에서 받은 값은 숫자처럼 보여도 문자열일 수 있습니다. 이 문제를 이해하지 못하면30분과10분을 더했는데3010이라는 결과가 나올 수 있습니다.

```javascript console
const first = "30";
const second = "10";
console.log(first + second);
console.log(Number(first) + Number(second));
```

```text
3010
40
```

첫 출력에서는 두 문자열을 이어 붙입니다. 둘째 출력에서는 `Number`로 각각 숫자값으로 바꾼 뒤 더합니다. 같은 `+` 기호라도 피연산자의 종류에 따라 우리가 기대하는 덧셈과 다른 결과가 나올 수 있습니다. 그래서 화면에서 무엇처럼 보이는지보다 실제 값의 종류를 확인해야 합니다.

`Number`를 사용한다고 모든 입력이 유효한 시간이 되는 것은 아닙니다. `Number("hello")`는 정상적인 숫자로 바꾸지 못해 `NaN`이라는 값을 만듭니다. 이것은 숫자가 아니라는 뜻의 특수한 숫자값 표현입니다. 빈 문자열을 `Number`로 바꾸면0이 될 수 있다는 점도 중요합니다. 빈 입력을 먼저 거절하려는 요구사항이라면 변환 전에 검사해야 합니다.[3]

```javascript console
const raw = " 25 ";
const cleaned = raw.trim();
const minutes = Number(cleaned);
console.log(cleaned);
console.log(minutes + 5);
console.log(Number.isFinite(minutes));
```

```text
25
30
true
```

`trim()`은 문자열의 양끝 공백을 제거한 새 문자열을 돌려줍니다. 원래 문자열 안의 모든 공백을 지우는 것이 아닙니다. `"HTML 기초"`의 단어 사이 공백은 이 기능으로 없어지지 않습니다. Python에서 본 `strip()`과 비슷한 목적을 가진 기능이지만 이름이 같지는 않습니다.

`Number.isFinite`는 유한한 숫자인지 확인하는 기능입니다. 기록장에서는 정수인지 확인하는 `Number.isInteger`도 사용할 것입니다. 처음 보는 기능을 모두 외우기보다 ‘문자열 정리’, ‘숫자 변환’, ‘허용 조건 검사’라는 세 일을 구분해서 읽는 것이 중요합니다.

### 연습 7-2. 빈칸을0으로 저장한 오류

빈 문자열을 곧바로 Number로 바꾸고,0도 저장 가능한 값으로 처리했습니다. 요구사항은 ‘사용자가 시간을 적지 않으면 거절한다’입니다. 검사 순서를 어떻게 바꾸어야 할까요?

### 풀이 7-2

먼저 문자열의 앞뒤 공백을 정리하고 빈 문자열인지 확인해야 합니다. 빈 값이면 변환 결과0을 사용하지 않고 입력을 요청합니다. 내용이 있을 때 숫자로 바꾸고, 유효한 숫자인지와 허용 범위를 확인합니다. 변환은 사용자의 의도를 판단해 주는 기능이 아닙니다.

‘빈 입력’과 ‘사용자가 실제로0을 입력함’을 같은 숫자 결과로 만들어 버린 뒤에는 원래 상황을 구분하기 어려워질 수 있습니다. 필요한 구별은 정보를 잃기 전에 검사해야 합니다.

## 7.3 조건문은 괄호 안의 판단에 따라 길을 나눈다

Python에서 들여쓰기로 조건문의 범위를 읽었다면 JavaScript에서는 중괄호를 보게 됩니다.

```javascript console
const minutes = 45;
if (minutes >= 30) {
  console.log("목표 시간에 도달했습니다.");
} else {
  console.log("조금 더 공부할 수 있습니다.");
}
```

```text
목표 시간에 도달했습니다.
```

`if` 뒤 괄호에는 판단할 조건이 들어 있습니다. `minutes >= 30`은45가30 이상인지 비교하므로 true입니다. 그 결과 첫 중괄호 안의 출력이 실행됩니다. `else`는 그 조건에 해당하지 않을 때 실행할 다른 길입니다. 두 문장이 항상 모두 실행되는 것이 아닙니다.

JavaScript의 참과 거짓은 소문자 `true`, `false`입니다. Python의 `True`, `False`와 철자가 다릅니다. 값을 비교할 때 이 책에서는 기본적으로 `===`와 `!==`를 사용합니다. `===`는 값과 자료형을 강제로 맞춰 같은 것으로 취급하지 않는 엄격한 동등 비교입니다. 대입하는 `=`와 비교하는 `===`를 구분하세요.

```javascript console
console.log(30 === "30");
console.log(30 === 30);
console.log(30 !== 10);
```

```text
false
true
true
```

여러 조건은 `&&`와 `||`로 연결할 수 있습니다. 앞 트랙의 and와 or에 대응하는 역할을 먼저 떠올리면 됩니다. `!`는 참·거짓을 뒤집는 데 사용합니다. 다음 조건은 정수이면서1이상이고600이하인지 확인합니다.

```javascript console
const minutes = 40;
const valid = Number.isInteger(minutes) && minutes >= 1 && minutes <= 600;
console.log(valid);
```

```text
true
```

괄호 안에 숫자나 문자열 자체를 넣으면 JavaScript가 참·거짓으로 판단하는 규칙도 있습니다. 그러나 Python의 규칙과 모두 같지는 않습니다. 예를 들어 빈 배열은 JavaScript에서 참으로 취급될 수 있습니다. 목록이 비었는지 보려면 `records.length === 0`처럼 의도를 명확히 쓰는 편이 이 단계에서는 읽기 쉽습니다. 다른 언어에서 익숙한 축약을 그대로 옮기지 마세요.

### 연습 7-3. 경계값을 판단하기

시간 조건이 ‘1부터600까지의 정수’입니다.0,1,600,601,2.5를 넣었을 때 각각 통과하는지 정해 보세요. 왜 경계의 바로 안쪽과 바깥쪽을 함께 확인하는지도 설명해 보세요.

### 풀이 7-3

0은 실패,1은 통과,600은 통과,601은 실패,2.5는 정수가 아니므로 실패입니다. `>`와 `>=` 하나를 잘못 쓰면 경계값만 틀릴 수 있습니다. 예를 들어 `minutes > 1`이라고 적으면 허용해야 할1을 거절합니다. 평범한40만 시험하면 이런 오류를 발견하지 못할 수 있으므로 경계값을 따로 확인합니다.

## 7.4 함수는 설명용 이름과 실제 입력·반환으로 읽는다

다음 함수는 두 학습 시간을 더합니다.

```javascript console
function addMinutes(first, second) {
  const total = first + second;
  return total;
}

const result = addMinutes(20, 15);
console.log(result);
```

```text
35
```

`function`은 함수 정의를 나타냅니다. `addMinutes`는 우리가 정한 함수 이름입니다. 정의의 괄호 안에 있는 `first`, `second`는 매개변수입니다. 호출할 때 전달되는 값을 함수 안에서 부르기 위한 이름입니다. `addMinutes(20, 15)`를 호출하면 이번 호출의 first에는20, second에는15가 연결됩니다.

함수 안에서는20과15를 더해 total에35를 연결합니다. `return total`은 그 값을 호출한 쪽으로 돌려주고 이번 함수 실행을 끝냅니다. 그래서 호출 표현식의 결과35가 바깥의 result에 들어갑니다. `console.log(result)`가 그 값을 화면 본문이 아니라 콘솔에 보여 줍니다.

함수 이름에 add라는 말이 있다고 자동으로 더하는 것이 아닙니다. 본문을 빼기로 바꾸면 이름과 실제 동작이 어긋난 함수가 됩니다. 이름은 사람에게 의도를 알려 주는 중요한 설명이지만, 실행 규칙은 본문에 있습니다. 함수가 정의되어 있다고 본문이 그 자리에서 자동으로 한 번 실행되는 것도 아닙니다. 호출을 만나야 해당 입력으로 실행됩니다.

함수 선언의 이름을 사용할 수 있게 되는 시점에는 JavaScript의 별도 규칙이 있지만, 처음에는 선언을 위에 두고 호출을 아래에 두는 명료한 형태로 읽겠습니다. 이 책은 이 단계에서 선언 방식에 따른 고급 차이를 암기시키려는 교재가 아닙니다.

```javascript console
function showMinutes(minutes) {
  console.log(minutes);
}

const result = showMinutes(12);
console.log(result);
```

```text
12
undefined
```

이 함수는12를 출력했지만 명시적으로 값을 반환하지 않았습니다. 호출 결과는 `undefined`입니다. Python의 print와 return이 달랐듯이, JavaScript에서도 콘솔 출력과 반환은 별개입니다. `undefined`는 여기에서 ‘함수가 반환한 값이 따로 없다’는 상황에 나타났습니다. 모든 undefined가 같은 원인인 것은 아닙니다. 없는 객체 속성을 읽었을 때도 볼 수 있습니다.

### 연습 7-4. 값을 다음 계산에 사용하기

학습 시간을 두 배로 계산해 다음 코드에서 사용하려고 합니다. 그런데 함수 안에서 `console.log(minutes * 2)`만 했습니다. 함수 호출 결과를 숫자로 받으려면 어떤 일을 해야 할까요?

### 풀이 7-4

함수에서 계산한 값을 `return minutes * 2;`처럼 반환해야 합니다. 출력도 필요하다면 호출한 쪽에서 반환값을 출력할 수 있습니다. ‘값을 계산한다’, ‘돌려준다’, ‘어딘가에 보여 준다’를 분리하면 함수를 다른 기능에서도 재사용하기 쉽습니다.

```javascript console
function doubleMinutes(minutes) {
  return minutes * 2;
}

const doubled = doubleMinutes(18);
console.log(doubled + 4);
```

```text
40
```

## 7.5 배열과 객체로 여러 기록을 묶기

Python의 리스트처럼 여러 값을 순서대로 담는 데 JavaScript 배열을 사용할 수 있습니다. 한 기록에 주제와 시간을 묶으려면 객체를 사용할 수 있습니다. 중괄호는 함수의 범위를 감쌀 때도 보았지만, 값이 놓인 위치에서는 객체를 표현할 수도 있습니다. 기호 하나의 뜻을 주변 문맥 없이 고정하면 안 됩니다.

```javascript console
const record = {
  topic: "HTML",
  minutes: 25,
  completed: false
};

console.log(record.topic);
console.log(record["minutes"]);
```

```text
HTML
25
```

`topic`, `minutes`, `completed`는 객체의 속성 이름입니다. 각 콜론 오른쪽에 해당 값이 있습니다. `record.topic`은 record 객체의 topic 속성을 읽습니다. `record["minutes"]`는 대괄호 안에 적은 이름으로 값을 읽는 다른 표현입니다. 화면에 ‘HTML’이라는 제목 요소를 만드는 것은 아닙니다. 아직은 프로그램 안의 데이터입니다.

이 객체들을 배열에 넣으면 여러 기록을 만들 수 있습니다.

```javascript console
const records = [
  { topic: "HTML", minutes: 25 },
  { topic: "CSS", minutes: 35 }
];

console.log(records[0].topic);
console.log(records.length);
```

```text
HTML
2
```

`records[0]`은 첫 번째 객체입니다. 그 객체의 `.topic`을 읽어 HTML이라는 값을 얻습니다. `records.length`는 배열의 항목 수입니다. 괄호가 없는 이유는 이 위치에서 함수를 호출한 것이 아니라 속성값을 읽었기 때문입니다. Python의 `len(records)`와 모양이 다르다고 완전히 새로운 개념인 것은 아닙니다.

배열에는 `push()`로 뒤에 값을 넣을 수 있습니다.

```javascript console
const topics = ["HTML"];
topics.push("CSS");
console.log(topics.length);
console.log(topics[1]);
```

```text
2
CSS
```

여기서 const인데 배열이 바뀌었습니다. const가 막는 것은 `topics = 다른배열`처럼 이름에 새 값을 다시 대입하는 일입니다. 이미 연결된 배열 내부에 값을 추가하는 일까지 막지는 않습니다. 앞 트랙의 이름과 객체, 재대입과 변경의 구별이 여기에서도 필요합니다.[2][3][5]

### 연습 7-5. const는 모두 얼려 버릴까?

`const record = { minutes: 20 };` 다음에 `record.minutes = 30;`을 실행하는 것과 `record = { minutes: 30 };`을 실행하는 것은 어떤 차이가 있나요?

### 풀이 7-5

첫 번째는 현재 객체의 속성을 바꿉니다. 두 번째는 record라는 이름에 다른 객체를 다시 대입하려 합니다. const 선언에서는 두 번째 재대입이 허용되지 않습니다. 첫 번째 내부 변경은 별도로 객체를 변경하지 못하게 만들지 않았다면 가능합니다.

이 차이를 모르면 ‘const를 사용했으니 원본 데이터가 절대 바뀌지 않는다’라는 잘못된 보장을 하게 됩니다. 원본 보존이 필요하면 변경 방식과 복사 여부를 따로 설계해야 합니다.

## 7.6 for...of로 배열을 하나씩 읽기

다음 예제는 기록들의 총 공부 시간을 계산합니다.

```javascript console
const records = [
  { topic: "HTML", minutes: 25 },
  { topic: "CSS", minutes: 35 },
  { topic: "JavaScript", minutes: 20 }
];
let total = 0;

for (const record of records) {
  total = total + record.minutes;
}

console.log(total);
```

```text
80
```

`for (const record of records)`는 records 배열에서 값을 하나씩 받아, 이번 반복에서 record라는 이름으로 사용한다는 뜻입니다. `record`는 사람이 정한 임시 이름입니다. 영어 문장을 이해해서 ‘기록’이라고 판단하는 것이 아닙니다. 첫 반복에서는 HTML 객체, 두 번째에서는 CSS 객체, 세 번째에서는 JavaScript 객체가 그 이름에 연결됩니다.

중괄호 안의 `record.minutes`는 이번에 꺼낸 객체의 시간입니다. total은 처음0에서25,60,80으로 바뀝니다. total이 let인 이유는 합계를 계산하면서 같은 이름에 새 숫자를 계속 대입하기 때문입니다. 각 반복의 record는 이번 항목을 부르는 이름으로 사용합니다.

JavaScript에는 `for...in`도 있지만 이 배열의 값들을 하나씩 읽는 예제를 같은 의미로 무심코 바꾸지 않습니다. 이름이 비슷한 반복 방식이라도 무엇을 꺼내 주는지 다를 수 있습니다. 이 책의 배열 항목 순회에서는 우선 `for...of`를 사용합니다.

### 연습 7-6. 합계가 마지막 값만 남는 이유

위 예제에서 `total = total + record.minutes`를 `total = record.minutes`로 바꾸면 최종 결과는 무엇인가요? 그 이유를 각 반복으로 설명해 보세요.

### 풀이 7-6

최종 결과는20입니다. 첫 반복에서 total을25로 바꾸고, 두 번째에서35로 바꾸고, 세 번째에서20으로 바꾸기 때문입니다. 이전 값에 더하지 않고 새 값으로 교체했습니다. 누적과 재대입의 오른쪽 표현식이 어떻게 다른지 확인하는 문제입니다.

‘for는 계속한다’라는 문장만 알아서는 이 차이를 설명할 수 없습니다. 이번 항목이 무엇이고, 그 항목을 사용해 어떤 대입을 하는지까지 연결해야 합니다.

## 7.7 낯선 짧은 함수 표현도 천천히 읽기

AI가 만든 JavaScript에서는 `=>`라는 기호를 자주 볼 수 있습니다. 화살표 함수라는 함수 표현 방식입니다. 다음 두 함수는 이 단순한 계산 예제에서 같은 결과를 냅니다.

```javascript console
function twiceA(value) {
  return value * 2;
}

const twiceB = (value) => value * 2;
console.log(twiceA(6));
console.log(twiceB(6));
```

```text
12
12
```

둘째 표현의 `value`는 입력을 부르는 이름이고, 화살표 오른쪽 식의 결과가 반환됩니다. 그러나 모든 함수 동작에서 일반 함수와 화살표 함수가 완전히 같다는 뜻은 아닙니다. this 같은 별도 차이가 있습니다. 지금은 AI 코드에서 이 표현을 보았을 때 ‘입력을 받아 결과를 만드는 함수구나’라고 알아보고, 필요하면 긴 형태로 풀어 읽는 데 집중하겠습니다.

중괄호를 넣은 화살표 함수에서는 반환을 명시해야 하는 경우를 주의합니다.

```javascript console
const twice = (value) => {
  return value * 2;
};
console.log(twice(9));
```

```text
18
```

### 연습 7-7. 화살표를 풀어 읽기

`const isLong = (minutes) => minutes >= 30;`이라는 코드가 있습니다. 이 함수에20을 넣고40을 넣으면 어떤 값을 돌려주나요? 함수 이름을 읽지 않고 본문만으로 설명해 보세요.

### 풀이 7-7

20이30이상인지 비교한 결과는 false이고,40이30이상인지 비교한 결과는 true입니다. 함수 이름이 isLong이라고 해서 ‘충분히 긴 공부’라는 현실 기준이 생기는 것이 아닙니다. 코드에 적힌 기준은30입니다. 기준을 바꾸려면 비교식의 값을 바꾸어야 합니다.

## 7.8 값을 만들었지만 아직 화면은 바꾸지 않았다

이 장의 코드로 시간을 계산하고, 객체를 만들고, 배열을 순회할 수 있게 되었습니다. 그러나 콘솔에80이 출력되었다고 HTML의 합계 문단이 자동으로80으로 바뀌는 것은 아닙니다. JavaScript의 데이터와 화면의 요소를 연결하는 단계가 남아 있습니다.

다음 장에서는 브라우저가 문서를 다룰 수 있도록 만든 DOM을 만납니다. 입력창을 찾고, 현재 값을 읽고, 제출이 일어났을 때 함수를 실행하고, 그 결과를 문서에 넣습니다. 지금 배운 함수와 조건문이 ‘나중에 버튼을 누르는 순간’과 어떻게 연결되는지 살펴보겠습니다.
